# A General Theory of Risk Sharing

Numerical replication of selected results from *A General Theory of Risk
Sharing* (working paper). All page/section references below (e.g. "p.7",
"Theorem 2") refer to this paper.

The paper develops the risk-sharing problem for a continuum of agents
indexed by a general measure space (A, mu), each endowed with a convex risk
measure rho_a, and studies the integral infimal convolution

    (box_{a in A} rho_a mu(da))(X) = inf { int_A rho_a(X_a) mu(da) : int_A X_a mu(da) = X }.

It proves a general duality theorem (Theorem 1, p.9) and specializes it to
two families of risk measures that are built from a single base risk measure
by varying one parameter across agents: *dilations* (Section 4.1, entropic
risk measures, Theorem 2) and *inflations* (Section 4.2, expected shortfall,
Theorems 3-4), and applies the latter to Pareto efficiency with a continuum
of agents (Section 5, Theorem 5).

This repository is a purely numerical companion: there is no market data
involved anywhere in the replication. Every experiment works with a finite
probability space (a direct, explicit approximation of L^infty(P)) and an
explicit discretization of the agent space A, and checks the paper's closed
form value functions, optimal allocations, and dual representations against
brute-force convex optimization with `cvxpy`.

## Experiments

| Script | Paper result verified |
|---|---|
| `exp.exp1` | Theorem 2 / Example 8 (p.11-13): dilated (entropic) risk sharing, value function Ent^Gamma and optimal allocation X_a = gamma_a X / Gamma, continuum vs. finite agents. |
| `exp.exp2` | Theorems 3-4, Proposition 4-5 (p.15-19): inflated (expected shortfall) risk sharing; value function at the essential infimum of gamma_a, existence of an optimizer iff there is an atom at the infimum, non-existence otherwise. |
| `exp.exp3` | Theorem 5, Proposition 6 (p.20-22): non-existence of Pareto efficient allocations with a continuum of ES preferences and no atom at the essential supremum of beta_a; explicit Pareto improvements; comparison with the finite-agent case where an optimum always exists. |
| `exp.exp4` | Theorem 1 (p.9) and Proposition 3 (p.9-10): the dual representation of the integral infimal convolution and the first-order optimality condition via a common subgradient, for both entropic and expected-shortfall agents. |

## Repository layout

```
src/            risk measures, risk-sharing / infimal-convolution machinery, config, reporting
exp/            one script per experiment, run as a module
data/           synthetic data generators (finite probability space, aggregate endowment X)
tests/          pytest unit tests of src/
results/        JSON metrics, PNG plots, and RESULTS.md written by the experiments
```

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

No API keys or market data are required: every input is synthetic and
generated by `data/generate_synthetic.py`.

## Running

```bash
python -m pytest -m "not market_data"   # unit tests (no market_data tests exist in this repository)
python -m exp.exp1
python -m exp.exp2
python -m exp.exp3
python -m exp.exp4
```

or simply

```bash
./reproduce.sh
```

which runs the test suite followed by all four experiments and leaves their
artifacts in `results/`.

## Results

See `results/RESULTS.md` for the numbers produced by the final run of each
experiment, compared against the paper's theorems, together with the
"Deviations from the paper" and "Not reproduced" sections.
